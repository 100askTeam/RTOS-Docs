第 3 课：有源/无源蜂鸣器

本课下载预编译固件 03_buzzer_demo.zip（解压得 03_buzzer_demo.hex）并通过 DshanPI USBToolBox 烧录，快速体验底板 M9 插座上的无源/有源蜂鸣器驱动，利用 PA7 (TIM3_CH2) 输出三段变频提示音并支持一键静音。

实验前务必确认已拔除 M4 红外发射模块！

底板 M9（蜂鸣器） 与左侧 M4（红外发射管） 共用同一引脚 PA7！ 如果两者同时插在底板上，M4 红外灯珠回路会将 PA7 对地拉低，导致低电平触发的蜂鸣器模块在 MCU 静音或空闲时仍持续微导通并出现明显发热。请务必先拔下 M4 后再插接 M9！

预期现象与串口日志​

烧录并运行后，观察蜂鸣器发声、M1 OLED 屏幕与串口终端（115200 8-N-1）：

  1. 变频提示音循环：固件连续输出低/中/高三音节（2000 Hz 150 ms -> 2500 Hz 150 ms -> 3000 Hz 350 ms，期间核心板 LED1 点亮），随后静默休息 2 s（期间关闭 PA7 设为高阻态防发热），循环往复；
  2. 按键静音开关：按下底板 K1 (PB1) 或核心板 KEY0 (PE3)，可随时切换静音（M1 OLED 顶部切换为 BUZZER [MUTE]，中间大字号显示 MUTED）；再按一次立即恢复发声；
  3. OLED 与串口输出示例：
buzzer_demo: M9 on PA7 TIM3_CH2 (press K1/KEY0 to mute)
[BUZZER] pattern #1
[BUZZER] pattern #2
[BUZZER] mute=ON
[BUZZER] mute=OFF

常见问题排查​

现象排查方向
蜂鸣器发烫或不响的时候仍有微弱“滋滋”电流声立即检查左侧 M4 红外发射模块 是否忘拔！拔掉 M4 即可彻底断开下拉回路
有源蜂鸣器听起来音调都一样有源蜂鸣器内部自带固定频率振荡源，三声响声均同音属正常现象；换用背面带绿色 PCB 的无源蜂鸣器可听出低/中/高三种音调
确认插对且未静音却完全不响检查 M9 3 针排母顺序（VCC/GND/IO 切勿反插）；可按一下 K1 确认没有误触静音状态
